# Rubric: is this reproduction package ready to post?

## Checks

| Check                           | Evidence                                                                                                                                                                  | Pass condition                                                                                                                                                                                                                                                                                                                      | Weight    |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| Environment                     | The repro report's environment record, read against the issue context and repo-facts block for relevant version, OS, installation method, dependencies, or configuration. | Pass if the environment contains the details needed to interpret the reproduction and matches the issue's relevant target environment, or any meaningful differences are stated and justified.                                                                                                                                      | preferred |
| Followable steps                | The repro report's starting state, input, setup, commands, options, and actions, read against the issue context and repo instructions.                                    | Pass if another person could follow the reproduction from the stated starting state to the tested behavior without having to guess a material step.                                                                                                                                                                                 | required  |
| Input                           | The reproduction input, configuration, fixture, or test case, read against the triggering conditions described in the issue.                                              | Pass if it matches the issue's triggering conditions, or any differences are justified and still exercise the same behavior.                                                                                                                                                                                                        | required  |
| Command                         | The commands, options, and relevant configuration used in the repro report, read against the issue and repository instructions.                                           | Pass if they test the same operation described by the issue. Exact textual equality is not required when an equivalent command or option set exercises the same path.                                                                                                                                                               | required  |
| Target behavior                 | The input, command, and resulting artifact read together against the behavior described in the issue.                                                                     | Pass if the attempted reproduction is aimed at the same bug or behavior described by the issue, rather than an adjacent failure, setup problem, or different code path.                                                                                                                                                             | required  |
| Output                          | The terminal output, logs, screenshots, stack traces, or other artifacts, read against the issue's reported behavior and the repro report's stated outcome.               | Pass if the artifact honestly demonstrates the reported reproduction result. A matching failure passes; a successful run or different result also passes when it is evidence for an honest cannot-reproduce of the correct target. Fail when the artifact shows a different failure but the report claims the issue was reproduced. | required  |
| Expected vs actual              | The repro report's expected and actual outcomes, read against the issue description and supporting artifacts.                                                             | Pass if the package makes clear what was expected and what actually happened, and those statements agree with the evidence.                                                                                                                                                                                                         | preferred |
| Evidence supports claims        | The claim comment and repro report read against the output, logs, screenshots, and other artifacts.                                                                       | Pass if every material claim about reproduction or non-reproduction is supported by the shown evidence and does not overstate what was demonstrated.                                                                                                                                                                                | required  |
| Repo communication requirements | The claim comment read against the repo-facts block, repository contribution guidance, issue templates, and any disclosure requirements.                                  | Pass if the proposed comment satisfies any applicable repository requirements, including required AI-use disclosure, and does not omit information the repository explicitly requires.                                                                                                                                              | required  |
| Comment accuracy                | The claim comment read against the issue context and repro report.                                                                                                        | Pass if the comment accurately summarizes the tested environment, result, and relevant limitations without introducing unsupported conclusions.                                                                                                                                                                                     | preferred |

## Verdict rule

Ready only if every required check passes.

Hold if any required check fails or is unclear.

Preferred checks do not change the verdict.

An evidenced cannot-reproduce result can still be Ready when the package clearly targets the correct issue, the reproduction steps are followable, and the comment accurately reports the result.

A different error does not count as reproducing the issue unless the package provides evidence that it is the same underlying behavior described by the issue.
